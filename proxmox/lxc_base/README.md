# lxc_base

> **Deprecated.** Use [`proxmox/lxc`](../lxc/). See [MIGRATION.md](../../MIGRATION.md).

Plain Proxmox LXC container (no Docker, no provisioning). Still on master only because `lxc_docker_host` and `lxc_docker_nvidia_host` at tags v2.0.2 and v3.0.0 load it from the default branch without a `?ref=`; its interface is frozen until those consumers are gone.
